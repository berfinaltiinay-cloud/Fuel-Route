# Fuel-Route
Smart fuel and route assistant
FuelRoute 🚗⛽
FuelRoute is a smart fuel and route assistant designed to help drivers plan their journeys more efficiently.
The application allows users to enter their starting point, destination, vehicle information, fuel type, and current fuel level. Based on this information, FuelRoute calculates the estimated route distance, fuel consumption, and whether the available fuel is sufficient for the journey.
The application also aims to recommend fuel stations located along the selected route, helping drivers avoid unnecessary detours.
